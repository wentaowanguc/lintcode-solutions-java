## Last Position of Target
### Description
Given a sorted array (ascending order) and a `target` number, find the last index of this number in `O(logn)` time complexity.

In the `target` does not exit in the array, return `-1`.

### Example
Given `[1, 2, 2, 4, 5]`
For `target = 2`, return `2`
For `target = 4`, return `3`
For `target = 6`, return `-1`
